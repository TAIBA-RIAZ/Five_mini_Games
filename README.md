# 🎮 Mini Games Collection!
Welcome to Mini Games!!! 
— a fun Python-based collection of five classic games you can play right in your terminal. This project is perfect for beginners learning programming or anyone who wants to revisit these nostalgic games.

---

## 🕹️ Included Games
### Game	Description
#### 1. Guess the Number	: 
Try to guess the secret number chosen by the computer within limited attempts.
#### 2. Rock, Paper, Scissors :
A classic hand game against the computer with simple win/lose logic.
#### 3. Wordle	:
A Python terminal version of the popular word guessing game. Guess the 5-letter word in 6 tries!
#### 4. Connect Four	:
Drop your chips into the grid and try to connect 4 in a row before the computer does.
#### 5. Tic Tac Toe :
A two-player or player vs. computer game to get 3 in a row. Smart move logic included.

---

## 🚀 How to Play
### Clone the repository:

git clone https://github.com/TAIBA-RIAZ/Five_mini_Games.git
- cd mini-games

### Run the game launcher (if you made one):
python main.py

### Or run any game individually like:
python tic_tac_toe.py
